# ordinario-ftw
# Sistema de Disponibilidad de Salones

Proyecto Final de Fundamentos de Tecnologías Web.

## Responsable

Carlos Vicente López Rosales

## Descripcion

Se trata de una aplicacion web para consultar los salones dispobibles de la FEI y poder hacer uso de estos como estudiante.

## Funcionalidades

- Consulta de salones
- Disponibilidad de aulas
- Login validado con XML
- Filtros dinámicos para ver el estado del salon.
- Diseño basico

## Tecnologías

- HTML
- CSS
- JavaScript
- XML
- XSD

## Prompts utilizados

- Propón una estructura de navegación para un sitio web de consulta de salones que incluya varias páginas y una distribución clara de la información.
- Revisa la estructura HTML de mi página web y sugiere mejoras relacionadas con encabezados, navegación y elementos semánticos.
- Verifica si la estructura de mi página HTML cumple buenas prácticas de organización utilizando header, nav, main, section y footer.
- Ayuda a identificar posibles errores en rutas relativas de archivos CSS, JavaScript e imágenes dentro de mi proyecto web.
- Ayuda a rediseñar el menu de las paginas con botones uniformes, redondeados y con un efecto llamativo.
